# App2 — Localização GPS

Aplicativo Android desenvolvido em Kotlin.

Responsável por obter as coordenadas GPS do Samsung Galaxy A23 e publicá-las no HiveMQ Cloud pelo tópico `estacao/localizacao`.

A localização é integrada ao backend e apresentada no App1.

**Status:** aplicativo desenvolvido, testado e funcional.

Código-fonte em preparação para publicação.
